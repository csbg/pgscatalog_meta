================================================================================
SECTION 2. DISTINCT SAMPLES VS REPEATED MEASURES
================================================================================

Measurements are NOT from independent biological replicates in the
conventional experimental sense. The analysis uses repeated evaluations
of the same polygenic score (PGS) across distinct evaluation sample sets
and cohorts drawn from the PGS Catalog.

Evidence (analysis/04_PGS_systemic_portability_unique_pss.R, analysis/06_meta_ivw.R):
  - The same PGS_id is evaluated in multiple performance metrics (PPM)
    linked to different evaluation sample sets (PSS).
  - R-tight deduplication (step 04) retains one PPM per (PGS x PSS x
    evaluation ancestry), but the same PGS still appears across many PSS/cohorts.
  - Stage-1 pooling (step 06) aggregates k_eval distinct evaluations within
    each (trait x PGS x ancestry) cell; k_eval records the repeat count.
  - Paired delta-AUC comparisons (step 08) pair the SAME PGS across European
    vs target evaluation ancestry within the same training bucket.

Interpretation for reviewers:
  n_pairs counts distinct PGS (not distinct individuals).
  Per-evaluation sample sizes (cases/controls/individuals) describe the
  cohorts in which each PGS was evaluated, not a single controlled trial.

================================================================================
SECTION 3. STATISTICAL METHODS AND INFERENCE
================================================================================

Analysis stage                          Method                          Inference
--------------------------------------------------------------------------------
Stage-1 AUC pooling                     Fixed-effect IVW on logit(AUC)  Estimation
Stage-2 AUC pooling (across PGS)        Fixed-effect IVW on logit(AUC)  Estimation
Heterogeneity assessment                Cochran Q, I-squared            Diagnostic
Heterogeneity exclusion                 I2 > 80% when k_eval >= 2       Filter
Delta-AUC point estimate (forest)     IVW of per-PGS differences      Estimation
Delta-AUC inference (main figure)       95% CI for delta_hat            CI excludes 0
Weighted intercept-only lm              IVW mean via lm(diff ~ 1)       Optional p-value

Primary estimand (main figure):
  delta-AUC = AUC_target - AUC_European
  Pooled across PGS within each (trait x training bucket x target ancestry)
  cell by inverse-variance weighting.

Primary inference rule (main figure):
  Significance is assessed by whether the 95% confidence interval for
  pooled delta-AUC excludes zero:
    - lo > 0  -> higher AUC in target ancestry than European reference
    - hi < 0  -> lower AUC in target ancestry (reduced portability)
    - lo <= 0 <= hi  -> inconclusive; CI includes zero
  P-value thresholds are NOT used for main-figure interpretation.

IVW implementation (analysis/08_generate_publication_figures.R):
  Per PGS i within each cell:
    diff_i    = AUC_target_i - AUC_European_i
    diff_se_i = sqrt(SE_European_i^2 + SE_target_i^2)

  Pooled point estimate and CI (used in forest plot and deltaAUC sheet):
    w_i       = 1 / diff_se_i^2
    delta_hat = sum(w_i * diff_i) / sum(w_i)
    se_hat    = sqrt(1 / sum(w_i))
    lo        = delta_hat - 1.96 * se_hat
    hi        = delta_hat + 1.96 * se_hat

  Weighted intercept-only linear model (equivalent IVW estimator):
    model     = lm(diff ~ 1, weights = 1 / diff_se^2)
    estimate  = coef(model)[1]   # equals delta_hat
    p-value   = summary(model)$coefficients[1, 4]   # two-sided Pr(>|t|)
                  tests H0: weighted mean delta-AUC = 0 when n_pairs >= 3

  The lm fits an inverse-variance-weighted mean of diff; it is not a
  covariate-adjusted regression. The p-value is a supplementary consistency
  check of the same null hypothesis; the main figure uses delta_hat and CI only.

================================================================================
SECTION 4. COVARIATES TESTED / STRATIFICATION VARIABLES
================================================================================

This is a meta-analysis of published PGS Catalog performance records, not
a primary GWAS or prospective cohort analysis. Stratification variables
used in the portability analysis are:

  1. trait_label
     Harmonized phenotype label (EFO-preferred where available)

  2. ancestry_display (evaluation ancestry)
     Ten display categories; European is reference for delta-AUC

  3. trained_bucket (training ancestry of the PGS)
     Five buckets derived from GWAS/development sample ancestry composition

  4. Sample size / effective sample size (Neff)
     Used as inverse-variance weights in pooling, not as a regression covariate

PGS Catalog performance record covariates:
  Individual performance metrics in the PGS Catalog may include model
  covariates (e.g., age, sex, principal components) recorded in the
  covariates_included_in_the_model field. The pipeline does not fit new
  regression models on individual-level data. It meta-analyzes published
  AUC estimates. Where multiple performance records exist for the same
  PGS x sample set x ancestry, R-tight deduplication selects one record
  (preferring larger Neff / n, then highest AUC; analysis/04_PGS_systemic_portability_unique_pss.R).

No additional covariates (e.g., sex, age) are tested as effect modifiers
in the main delta-AUC forest analysis.

================================================================================
SECTION 5. ASSUMPTIONS AND CORRECTIONS
================================================================================

Transformations and variance model
  - AUC pooled on logit scale: eta = qlogis(clamp(AUC, eps, 1-eps))
  - Per-study logit SE from 95% CI: SE = (qlogis(hi) - qlogis(lo)) / (2*1.96)
  - Missing CIs inferred by Hanley-McNeil variance from case/control counts
    when AUC is reported but CI is absent (analysis/05_pgs_auc_ci_audit.R)
  - Pooled AUC back-transformed: AUC_pooled = plogis(eta_pooled)

Meta-analysis assumptions
  - Fixed-effect inverse-variance weighted model (not random-effects)
  - No tau-squared (between-study variance) estimated
  - Independence of European and target SEs assumed for delta SE:
      SE_delta = sqrt(SE_EUR^2 + SE_target^2)   [conservative]

Heterogeneity
  - Cochran Q: Q = sum(w * (eta - eta_hat)^2), df = k - 1
  - I-squared: I2 = max(0, (Q - df) / Q) * 100
  - Exclusion rule (analysis/07_i_square_filter.R): remove cells where
      k_eval >= 2 AND I2 > 80%

Normality
  - No formal normality test applied (no Shapiro-Wilk or equivalent)
  - 95% CIs for delta-AUC use large-sample normal approximation (z = 1.96)
    on the IVW standard error

Inference rule (main figure)
  - Primary significance criterion: 95% CI for delta-AUC excludes zero
  - No p-value threshold applied to the main faceted forest plot
  - No multiple-comparison correction applied to main-figure inference

Exploratory output (not used for main-figure conclusions)
  - Benjamini-Hochberg FDR-adjusted p-values are optionally computed in
    paired_weightedtest_by_bucket_rebuilt_<STAMP>.csv for sensitivity checks
  - These test H0: IVW mean delta-AUC = 0 via the weighted lm when n_pairs >= 3
  - FDR results are supplementary and not used for main-figure interpretation

Reproduction gate (main figure trait selection; analysis/08_generate_publication_figures.R)
  - Training buckets: European-only OR Multi incl. EUR
  - Traits retained only if any tile has n_pairs >= 2
  - Result: 10 traits in faceted forest (reproduction_gate_keep_traits)

Confidence intervals
  - All delta-AUC CIs reported at 95% (delta_hat +/- 1.96 * se_hat)
  - Stage-1 AUC CIs use z = 1.96 on the logit scale

KEY FORMULAS (for reviewer traceability)
================================================================================

1. Logit transform and SE from 95% CI (analysis/06_meta_ivw.R):
     eta = qlogis(clamp(AUC))
     SE  = (qlogis(CI_hi) - qlogis(CI_lo)) / (2 * 1.96)

2. Fixed-effect IVW pooling (analysis/06_meta_ivw.R):
     w       = 1 / SE^2
     eta_hat = sum(w * eta) / sum(w)
     SE_hat  = sqrt(1 / sum(w))
     AUC_pooled = plogis(eta_hat)
     95% CI: plogis(eta_hat +/- 1.96 * SE_hat)

3. Cochran Q and I-squared (analysis/06_meta_ivw.R):
     Q  = sum(w * (eta - eta_hat)^2),  df = k - 1
     I2 = max(0, (Q - df) / Q) * 100

4. Hanley-McNeil variance (analysis/05_pgs_auc_ci_audit.R):
     Q1 = A / (2 - A),  Q2 = 2*A^2 / (1 + A)
     varA = (A*(1-A) + (n_cases-1)*(Q1-A^2) + (n_controls-1)*(Q2-A^2))
            / (n_cases * n_controls)

5. Per-PGS delta-AUC (analysis/08_generate_publication_figures.R):
     delta_i = AUC_target_i - AUC_European_i

6. Pooled delta-AUC and CI (analysis/08_generate_publication_figures.R):
     w_i = 1 / (SE_target_i^2 + SE_EUR_i^2)
     delta_hat = sum(w_i * delta_i) / sum(w_i)
     se_hat    = sqrt(1 / sum(w_i))
     95% CI: delta_hat +/- 1.96 * se_hat

7. IVW pooled delta-AUC via weighted intercept-only lm
   (analysis/08_generate_publication_figures.R):
     model = lm(diff ~ 1, weights = 1/(SE_EUR^2 + SE_target^2))
     Intercept = IVW mean delta-AUC (= delta_hat)
     Primary inference: lo = delta_hat - 1.96*se_hat, hi = delta_hat + 1.96*se_hat
     Significance: CI excludes zero (lo > 0 or hi < 0)

8. Optional exploratory p-values (analysis/08_generate_publication_figures.R):
     p.value = summary(model)$coefficients[1, 4]   # two-sided Pr(>|t|), n_pairs >= 3
     p.adj   = p.adjust(p.value, method = "fdr")   # not used for main figure
