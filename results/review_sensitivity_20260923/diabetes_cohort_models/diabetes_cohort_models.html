Type 2 diabetes: PGS that share a sample set

Catalog stamp 20260923. In the models, cohort means the sample set.

The input I need: which of the four models should account for several PGS evaluated on the same sample set, or whether you would rather drop rows than model the sharing.
  • lm(AUC ~ ancestry + PGS)
  • lm(AUC ~ ancestry + PGS, weights = 1/SE^2)
  • lmer(AUC ~ ancestry + PGS + (1|cohort), weights = 1/SE^2)
  • lmer(AUC ~ ancestry + (1|PGS) + (1|cohort), weights = 1/SE^2)

An evaluation is one AUC: one PGS, one sample set, one ancestry group, and one standard error. The sample-set term marks which evaluations share a sample set. It does not make the AUCs independent.

The four models are fit on type 2 diabetes. They can separate an ancestry group from a sample set only when a comparison uses more than one target sample set. Eight comparisons do. Seven are type 2 diabetes. The eighth is breast cancer, Europeans and South Asian participants, European-only training.

Seventeen comparisons have several PGS and one target sample set. Ancestry group and sample set are the same column there. The four models are not for that case. Five comparisons have one PGS.

Sample-set term, PGS fixed: lmer(AUC ~ ancestry + PGS + (1|cohort), weights = 1/SE^2)

In this model, cohort is the sample set. Evaluations from the same sample set share an offset, and the PGS stays a fixed intercept. Ten South Asian PGS share PSS011749, and all of them are South Asian, so the sample-set offset and the ancestry coefficient compete for the same shift.

If dropping rows is preferred to modelling the sharing

Two ways to drop rows, counted on the 71 type 2 diabetes evaluations. The page does not pick one.

  • One PGS per sample set, the lowest PGS identifier: keeps 33 evaluations, drops 38 of 71.
  • The largest sample set when one PGS is evaluated more than once in an ancestry group: keeps 65 evaluations, drops 6 of 71.
If you would rather drop rows than model the sharing, which rule do you prefer: one PGS per sample set, or the largest sample set when one PGS is evaluated more than once?
